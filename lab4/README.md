# Machine Learning

## Lab 4 – Exploratory Data Analysis

## Dataset
UCI Online Retail Dataset

## Objective
Perform exploratory data analysis (EDA) using Pandas, Matplotlib, and Seaborn to understand the dataset, its distributions, relationships, and trends.

## Dataset Description
The Online Retail dataset contains transaction records from a UK-based online retailer between December 2010 and December 2011. It contains 541,909 records and 8 variables.

## EDA Operations
The analysis includes:
- Data loading and initial inspection
- Data quality analysis
- Numerical analysis
- Country analysis
- Time-based analysis
- Grouping and aggregation
- Relationship analysis
- Data visualization using Matplotlib and Seaborn

## Files
- `Lab4.ipynb` – Jupyter Notebook containing the complete EDA
- `Online_Retail.csv` – Dataset used for the analysis
