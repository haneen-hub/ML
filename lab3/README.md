## Iris Dataset Classification

### Dataset Description

The Iris dataset is an open-source tabular dataset obtained from the UCI Machine Learning Repository. It contains 150 instances and four features describing iris flowers: sepal length, sepal width, petal length, and petal width.

The dataset also contains one target variable, `species`, which represents the species of the iris flower.

### ML Problem

This project is a **classification** problem. The goal is to use the sepal and petal measurements to predict the species of an iris flower.

### Target Variable

`species`

### Features

* `sepal_length`
* `sepal_width`
* `petal_length`
* `petal_width`

### Dataset File

The dataset is provided in `Iris.csv` and is loaded using Pandas in the Jupyter Notebook.

### Methodology

The planned machine learning workflow is:

**Dataset Selection → Data Loading → Data Preprocessing → Train/Test Split → Model Training → Model Evaluation → Results**
